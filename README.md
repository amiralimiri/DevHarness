# DevHarness

**A minimal coding agent harness in Python, built from scratch.**

---

## 🚀 What is DevHarness?

DevHarness is a lightweight, from-scratch **Python framework** that lets you build and run your own **autonomous coding agent**. Unlike heavy, complex agent frameworks, DevHarness keeps everything simple, transparent, and hackable — so you can actually understand how a coding agent works under the hood.

If you've ever wondered how a coding agent decides what to do next — from its reasoning loop to executing tools and managing tasks — this project is the perfect starting point.

---

## ✨ Key Features

### 🔁 Agentic Loops

The core of DevHarness. The agent can think, decide, execute tools, and take the next step based on results — just like a real developer working through a task. No hidden magic, just a clean loop you can trace and modify.

### 🤖 Subagents

The main agent can spawn specialized subagents and delegate tasks to them. This enables **multi-agent architectures**, letting you break down complex problems into smaller, focused pieces handled by different agents.

### 📦 Proper Python Package

The project is structured as a real **Python package**, managed with `pyproject.toml` and `uv`. Install it, import it, and drop it into your own projects with ease.

### 🧩 Built From Scratch

No black boxes. The code is clean, readable, and designed to be understood. Open any file, see exactly what's happening, and adapt it to your needs.

### 🖥️ Minimal UI/UX

A clean, distraction-free interface focused on what matters: interacting with the agent and seeing the results of its work.

### ⚡ Lightweight & Fast

No heavy dependencies. Just Python and a few essentials. Perfect for learning, prototyping, and even real-world use.
